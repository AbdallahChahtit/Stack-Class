# Stack-Class


Implements a stack using inheritance from ArrayList.
Stack Operations:
Table
Method	Description
push(Object)	Add element to top
pop()	Remove and return top element
peek()	Return top element without removing
isEmpty()	Check if stack is empty
getSize()	Return number of elements
Example:
plain
Input: A1 B2 C3 D4 E5
Output:
MyStack{}
peek: E5
5 strings are:
E5
D4
C3
B2
A1
